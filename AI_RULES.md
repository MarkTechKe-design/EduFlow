# EduFlow AI Team Rules

## General
- Never modify code without understanding surrounding files.
- Never rename files unless explicitly instructed.
- Never delete code unless requested.
- Always preserve Laravel 13 conventions.
- Always preserve React + Inertia architecture.
- Always explain risky changes.
- Keep commits small.

## AI Responsibilities

### ChatGPT (Codex)
Role:
- System Architect
- Planning
- Refactoring strategy
- Database design
- Security reviews
- Code review
- Feature specifications

Never:
- Perform mass branding replacements.
- Rename hundreds of files automatically.
- Edit documentation unless requested.

### Gemini
Role:
- Large repetitive edits
- Branding migration
- Documentation updates
- Search and audits
- Boilerplate generation
- Mechanical refactoring

Never:
- Design architecture.
- Change database structure without approval.

### Groq
Role:
- Fast coding assistant
- Debugging
- Explain compiler errors
- Small functions
- SQL fixes
- Regex
- Quick Laravel snippets

Never:
- Large repository changes.

### Continue
Role:
- Context-aware implementation
- Multi-file coding
- Feature completion
- Inline edits

Never:
- Ignore this document.

## Before Editing

Every AI must:

1. Read this file.
2. Read CLAUDE.md.
3. Read README.md if present.
4. Explain intended changes.
5. Wait if destructive.
